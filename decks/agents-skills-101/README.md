# Agents, Skills & MCP Servers: a practical 101

A talk about AI-supported development: how a team of agents, skills and MCP servers takes an issue from ticket to tested feature. Built with [Slidev](https://sli.dev).

```bash
npm install
npm run dev      # http://localhost:3030
npm run build    # static site in dist/
npm run export   # PDF, needs playwright-chromium
```

[`examples/`](examples/) holds the example agent and skill shown in the talk.
