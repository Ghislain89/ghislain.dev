Materials · 02

booker-platform.

The test object for both workshops: a small hotel booking app, built to practise testing with Playwright. It runs entirely on your own machine; there is no hosted copy, so you can't break anything for anyone else.

  1. What's inside

    • A web app (React) with a booking wizard, My bookings, messages, an admin area, a Dutch translation and dark mode
    • A REST API (Express, SQLite, JWT) with Swagger docs
    • Features that need the trickier Playwright APIs: downloads, live updates, a payment form in a shadow DOM, drag & drop and file uploads
    • Test hooks: reset and seed endpoints, plus feature flags that switch on bugs and chaos for the flaky-test clinic
    github.com/Ghislain89/booker-platform ↗

    Not set up yet? Follow the preparation steps.

  2. Reference solutions

    The solutions branch has a worked solution for every assignment, with page objects, fixtures and a CI workflow. Try it yourself first: there's more than one good answer.
